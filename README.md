# Asteroid-watch

## Project Idea
A web app for exploring near-Earth asteroids and their close approaches.
Tracking near-Earth objects helps NASA and the public understand potential
impact risks and supports planetary defense awareness.

## Technologies Used
- HTML, CSS, JavaScript
- NASA NeoWs (Near Earth Object Web Service) API
- Git & GitHub

## How to Run
1. Download or clone this repository.
2. Open the folder.
3. Open `index.html` in your browser.
