# Project Reflection

## What I Learned

During this project, I learned how to use GitHub to organize and manage a software project. I learned how to create issues, use labels, create branches, make commits, and create pull requests.

I also learned that breaking a project into smaller tasks makes it easier to manage and track progress.

## What Was Challenging

One challenging part was understanding how branches and pull requests work. At first, it was confusing to understand why changes should be made on a separate branch instead of directly on the main branch.

## What Was Fun

The most enjoyable part was designing the Asteroid Watch interface and creating a space-themed website.

## What I Would Improve

If I had more time, I would connect the project to a real NASA API so that the website could display live asteroid information. I would also add charts, asteroid search, and more interactive visualizations.
